## 一、一句话业务闭环

用户在浏览器中通过状态切换式虚拟简谱面板录入数字音符（含调号、拍号、速度设置），系统基于单一乐谱抽象语法树（Score AST）实时校验小节时值并按首调规则自动转译为垂直对齐的标准五线谱，点击播放后由高精度音频时钟驱动钢琴音色与节拍器发声，并在五线谱与简谱双视图上同步逐音高亮与平滑推进游标，同时自动保存工程到本地浏览器存储。

## 二、用户能走完的完整路径

1. **打开应用并创建新曲谱**
   - **用户动作**：在浏览器打开 NoteBridge 首页，点击「新建曲谱」或直接进入默认空白工程。
   - **系统响应**：初始化一份包含 1 个空白小节的 `ScoreDocument`（默认调号 `1=C`、拍号 `4/4`、速度 `90 BPM`、双谱对照视图），文档状态为 `CLEAN`，渲染空白五线谱谱表与简谱录入区，输入光标定位在第 1 小节起始位置。

2. **设定谱面基础参数**
   - **用户动作**：在顶部工具栏切换调号（`1=C` 至 `1=B` 共 12 个大调）、拍号（`2/4`、`3/4`、`4/4`、`6/8`）或拖动/输入速度（`40–200 BPM`）。
   - **系统响应**：立即更新 `ScoreDocument` 元数据；五线谱自动重绘对应调号升降记号与拍号，全部已有音符依据新调号实时重新计算固定调音高与五线谱位置（如 `1=G` 时简谱 `7` 自动映射到 `#F5` 位置），文档状态变为 `DIRTY`。

3. **选择修饰状态并录入音符**
   - **用户动作**：在虚拟面板选择音符时值（全/二分/四分/八分/十六分）、可选升降号（`#` / `b`）、高低音点（`-2` 到 `+2` 八度偏移）和附点状态，然后点击数字 `1–7` 或休止符 `0`。
   - **系统响应**：向当前光标所在小节写入 `NoteEvent` 并触发预览发声（即时播放对应 MIDI 音高钢琴音）；五线谱与简谱双视图同步渲染该音符；五线谱自动计算符干方向（三线及以上朝下，三线以下朝上）、八分/十六分音符按拍自动连杠（Beam）以及同小节临时升降号与还原号（`♮`）作用域；单次录入完成后临时修饰状态自动复位。

4. **自动小节校验与切分**
   - **用户动作**：连续录入音符填充当前小节。
   - **系统响应**：每写入一个音符，系统以 `480 Ticks = 1 拍` 汇总当前小节总时值并与拍号容量比对：时值恰好满拍时自动将小节状态置为 `VALID` 并开启下一小节；时值不足拍时标记 `UNDERFLOW` 并显示剩余空拍提示；若末尾音符导致总时值超出小节容量，小节标记为 `OVERFLOW` 并给出红色高亮与中文溢出提示，允许用户删除或撤回修正。

5. **编辑与修正音符**
   - **用户动作**：在五线谱或简谱中点击任意已录入音符或小节空白处定位光标，执行「删除音符」「插入小节线」「撤销」或「重做」。
   - **系统响应**：更新单一 `ScoreDocument` 数据模型并压入历史栈，双谱视图保持垂直 X 坐标严格对齐地重绘，并重新计算相关小节的 `MeasureValidityState`。

6. **切换视图模式**
   - **用户动作**：点击视图切换按钮，在「双谱对照（五线谱 + 简谱）」「仅简谱」「仅五线谱」三种模式间切换。
   - **系统响应**：不修改底层 `ScoreDocument`，瞬时切换画布渲染组合；切换后当前光标位置与后续编辑行为保持一致。

7. **开启节拍器与播放试听**
   - **用户动作**：可选开启「节拍器」开关，点击播放控制栏「播放」按钮。
   - **系统响应**：激活或解锁浏览器 `AudioContext`，加载内置钢琴音源采样（`PlaybackState` 从 `IDLE` 经 `LOADING_AUDIO` 进入 `PLAYING`），同时将虚拟输入面板置为 `LOCKED_BY_PLAYBACK` 防止误操作；由高精度音频时钟预调度触发钢琴音符与节拍器强弱拍滴答声，通过 `requestAnimationFrame` 读取音频播放进度，在五线谱与简谱上同步高亮当前发声音符及所在小节并平滑推进游标。

8. **播放控制与变速跟练**
   - **用户动作**：在播放过程中点击「暂停」「继续」「停止」、点击某小节编号执行「从指定小节起播」、开启/关闭「循环播放」，或在 `40–200 BPM` 范围内实时调节速度。
   - **系统响应**：音频调度器精确响应状态流转（`PLAYING ↔ PAUSED → IDLE`）与速度变更，游标与音符高亮保持与实际发声同步，停止后释放输入面板锁定（恢复 `READY`）。

9. **本地保存与重载恢复**
   - **用户动作**：点击「保存」按钮（或触发自动保存防抖）后刷新浏览器页面。
   - **系统响应**：将 `ScoreDocument` 序列化为带 `schemaVersion: 1` 的 JSON 写入 `localStorage`，文档状态经 `SAVING` 变为 `CLEAN`；刷新页面再次进入时自动读取本地存储并恢复上次编辑的曲谱内容与参数设置。

10. **演示模式校验路径（非生产环境受控开关）**
    - **用户动作**：在非生产环境中且配置 `VITE_ENABLE_DEMO_MODE=true` 时打开应用，点击「载入演示曲谱」按钮。
    - **系统响应**：页面顶部持久展示「演示环境」醒目标识，载入内置《小星星》示例工程供一键走通双谱对照、变速播放与同步高亮闭环。若在生产环境同时配置 `VITE_ENABLE_DEMO_MODE=true`，应用启动即报错终止，禁止进入页面。

## 三、明确不做（范围外与暂缓项）

1. **P1 阶段暂缓（本轮及 P0 不实现）**
   - 虚拟 88 键 / 双八度钢琴键盘录入及点击琴键反向换算简谱与五线谱。
   - PNG 高清长图导出与排版好的 PDF 乐谱导出。
   - 合成音频导出为 WAV / MP3 文件。
   - 标准 MIDI 与 MusicXML 文件的导入及导出。
   - 钢琴以外的多音色切换（吉他、弦乐、长笛等）。
2. **P2 阶段暂缓（本轮及 P0 不实现）**
   - 外接 MIDI 键盘（WebMIDI API / 蓝牙 / OTG）实时弹奏录入与节奏量化。
   - 拍照 / 截图光学乐谱识别（OMR / OCR）。
3. **架构与产品边界明确不做**
   - 不搭建后端 API 服务器、不建数据库表、不做账号登录与云端多端同步。
   - 不做多声部总谱、钢琴大谱表双手分轨（高音+低音双谱表）排版。
   - 不做复杂装饰音（倚音、波音、颤音、滑音）、连音（三连音等复杂异节奏）以及专业出版级符号手动拖拽微调。
   - 不接入真实支付、真实邮件通知、外部大模型服务或网络部署。

## 四、完成定义（P0 MVP 可勾选清单）

- [ ] 新建曲谱后默认以 `1=C`、`4/4`、`90 BPM` 初始化，支持 `1=C` 至 `1=B` 全部 12 个调号首调→固定调实时转译与自动升降号渲染。
- [ ] 支持 `2/4`、`3/4`、`4/4`、`6/8` 四种拍号及 `40–200 BPM` 速度调节，切换参数后已有曲谱实时重译且无错乱。
- [ ] 状态切换式虚拟简谱面板支持数字 `1–7`、休止符 `0`、高低音点（`-2..+2` 八度）、升降号（`#` / `b`）、增减时线（全/二分/四分/八分/十六分）、附点与小节线录入。
- [ ] 严格按 `480 Ticks = 1 拍` 校验小节时值，满拍自动开启下一小节，不足拍显示 `UNDERFLOW` 提示，超拍显示 `OVERFLOW` 红色告警。
- [ ] 五线谱自动处理符干朝向、按拍自动连杠（Beam）及同小节临时升降/还原号规则，并与简谱保持逐拍垂直 X 坐标对齐。
- [ ] 支持「双谱对照」「单简谱」「单五线谱」三种视图模式无损切换。
- [ ] 录入音符即时播放对应音高预览音；全曲播放支持播放、暂停、停止、指定小节起播、循环播放、节拍器开关及 `40–200 BPM` 实时变速。
- [ ] 播放期间由 Web Audio 时钟预调度驱动，双谱同步逐音高亮与平滑游标推进无明显肉眼错位，且虚拟录入面板自动锁定。
- [ ] 支持工程自动/手动保存至 `localStorage` 并通过刷新浏览器完整恢复。
- [ ] `VITE_ENABLE_DEMO_MODE` 默认为 `false`；生产环境开启该开关时启动阶段立即失败；演示环境下页面明确展示「演示环境」标识。
- [ ] L0–L6 自动化测试全部通过，无 S1 / S2 级别未闭环缺陷，页面全程无英文原始异常或堆栈信息暴露。
