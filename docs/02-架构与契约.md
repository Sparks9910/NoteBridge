# 02 · 架构与契约（NoteBridge / 音桥）

---

## 主选技术方案

- **主选技术栈**：`TypeScript 5 + React 19 + Vite 6 + npm` 纯前端本地优先 Web SPA；五线谱渲染采用 `VexFlow 5`，首调/固定调乐理换算采用 `tonal`，音频预调度与钢琴采样采用 `Tone.js + smplr`，状态管理采用 `Zustand`，单元测试与浏览器端到端验证采用 `Vitest + Playwright`。
- **选择理由**：在当前实测可用的 `Node v24.15.0 + npm 11.12.1` 环境下零后端依赖即可直接构建运行，且能够在同一前端内存模型中以单一 `Score AST` 低延迟驱动 VexFlow 五线谱、自研简谱 SVG 渲染器与 Web Audio 硬件时钟同步。

**单向依赖规则（严格执行）**：
- `ui` 只能依赖 `application`、`rendering`、`domain/types`。
- `rendering` 只能只读依赖 `domain`，禁止直接修改 `ScoreDocument`。
- `application` 依赖 `domain` 与 `infrastructure` 暴露的抽象接口。
- `infrastructure` 实现 `application` 定义的接口并可依赖 `domain`，禁止反向依赖 `ui` 或 `rendering`。
- `domain` 保持 100% 纯函数与纯类型，禁止引入 React、DOM、Window 或 Web Audio 全局对象。

## 二、核心状态机清单

所有状态机均在 `src/domain/state-machines.ts` 中以纯函数显式维护合法流转表；任何不在合法流转表中的触发事件一律拒绝，并返回错误码 `STATE_INVALID_TRANSITION`。

### 1. 音频播放状态机（`PlaybackState`）

- **状态集**：`IDLE`（空闲未播）、`LOADING_AUDIO`（解锁音频上下文与加载音源）、`PLAYING`（播放中）、`PAUSED`（暂停中）、`ERROR`（音频异常）。
- **合法流转**：
  - `IDLE` + `START_PLAY` → `LOADING_AUDIO`
  - `LOADING_AUDIO` + `AUDIO_READY` → `PLAYING`
  - `LOADING_AUDIO` + `AUDIO_FAILED` → `ERROR`
  - `LOADING_AUDIO` + `STOP` → `IDLE`
  - `PLAYING` + `PAUSE` → `PAUSED`
  - `PLAYING` + `STOP` → `IDLE`
  - `PLAYING` + `PLAY_COMPLETE` → `IDLE`（非循环模式）或 `PLAYING`（循环模式）
  - `PLAYING` + `AUDIO_FAILED` → `ERROR`
  - `PAUSED` + `RESUME` → `PLAYING`
  - `PAUSED` + `STOP` → `IDLE`
  - `ERROR` + `RESET_ERROR` → `IDLE`
- **非法流转拦截**：如 `IDLE` 收到 `PAUSE`、`PAUSED` 收到 `PAUSE`、`PLAYING` 收到 `START_PLAY` 等，一律抛出/返回 `STATE_INVALID_TRANSITION`。

### 2. 虚拟输入面板状态机（`InputPadState`）

- **状态集**：`READY`（就绪，无临时修饰激活）、`MODIFIER_ARMED`（已选定升降号/高低音点/附点等至少一项临时修饰）、`LOCKED_BY_PLAYBACK`（播放期间锁定，禁止录入）。
- **合法流转**：
  - `READY` + `ARM_MODIFIER` → `MODIFIER_ARMED`
  - `READY` + `COMMIT_NOTE` → `READY`（以当前默认四分音符直录）
  - `READY` + `LOCK` → `LOCKED_BY_PLAYBACK`
  - `MODIFIER_ARMED` + `ARM_MODIFIER` → `MODIFIER_ARMED`
  - `MODIFIER_ARMED` + `CLEAR_MODIFIER` → `READY`
  - `MODIFIER_ARMED` + `COMMIT_NOTE` → `READY`（录入后自动复位临时升降/八度/附点修饰，保留当前时值档位）
  - `MODIFIER_ARMED` + `LOCK` → `LOCKED_BY_PLAYBACK`
  - `LOCKED_BY_PLAYBACK` + `UNLOCK` → `READY`
- **非法流转拦截**：`LOCKED_BY_PLAYBACK` 状态收到 `ARM_MODIFIER` 或 `COMMIT_NOTE` 时一律拒绝并返回 `STATE_INVALID_TRANSITION`。

### 3. 小节时值校验状态机（`MeasureValidityState`）

- **状态集**：`EMPTY`（0 Ticks）、`UNDERFLOW`（0 < Ticks < 小节容量）、`VALID`（Ticks === 小节容量）、`OVERFLOW`（Ticks > 小节容量）。
- **合法流转**：任意状态在发生 `RECALCULATE_MEASURE(totalTicks, capacityTicks)` 时按确定性数学区间重算转移：
  - `totalTicks === 0` → `EMPTY`
  - `0 < totalTicks && totalTicks < capacityTicks` → `UNDERFLOW`
  - `totalTicks === capacityTicks` → `VALID`
  - `totalTicks > capacityTicks` → `OVERFLOW`
- **非法流转拦截**：`totalTicks < 0` 或 `capacityTicks <= 0` 属于非法输入，返回 `SCORE_INVALID_DURATION` / `STATE_INVALID_TRANSITION`。

### 4. 工程文档持久化状态机（`DocumentState`）

- **状态集**：`CLEAN`（与本地存储一致或刚新建未改）、`DIRTY`（内存已修改待保存）、`SAVING`（写入持久化中）、`SAVE_FAILED`（写入失败，如配额超限）。
- **合法流转**：
  - `CLEAN` + `MUTATE_SCORE` → `DIRTY`
  - `DIRTY` + `MUTATE_SCORE` → `DIRTY`
  - `DIRTY` + `BEGIN_SAVE` → `SAVING`
  - `SAVING` + `SAVE_SUCCEEDED` → `CLEAN`
  - `SAVING` + `SAVE_FAILED_ERR` → `SAVE_FAILED`
  - `SAVE_FAILED` + `MUTATE_SCORE` → `DIRTY`
  - `SAVE_FAILED` + `BEGIN_SAVE` → `SAVING`
- **非法流转拦截**：`CLEAN` 收到 `SAVE_SUCCEEDED` 等非正常次序事件一律返回 `STATE_INVALID_TRANSITION`。

## 三、接口约定

1. **时间单位**
   - **乐谱逻辑时值**：统一使用整数 `ticks`，固定每拍 `PPQ = 480`。全音符 = `1920`、二分音符 = `960`、四分音符 = `480`、八分音符 = `240`、十六分音符 = `120`；附点音符固定为原基础时值乘以 `1.5`（最小单位为 `180` ticks，均为整数）。
   - **音频调度与游标同步**：统一使用浮点数毫秒 `ms`（在调用 Web Audio `AudioContext` 时于 `audio-engine.ts` 边界换算为秒 `seconds = ms / 1000`）。
   - **持久化时间戳**：统一使用整数 Unix 毫秒 `epochMs`（`Date.now()`）。
2. **金额单位**
   - P0 无任何支付与计费模块（固定口径：`N/A-无金额模块`）。后续若扩展付费功能，统一采用整数分（`amountCents: number`）配 ISO 4217 币种码（例如 `"CNY"`），严禁浮点数金额。
3. **成功响应是否包外层结构**
   - 内部应用层/基础设施层同步与异步服务接口返回判别联合：`{ ok: true; value: T }` 或 `{ ok: false; error: AppError }`。
   - 预留未来后端 HTTP REST API 成功响应：**直接返回业务数据体 `T`**，不包外层 `{ data, code }` 壳。
4. **失败响应字段**
   - 所有服务失败与预留 HTTP 异常统一返回固定字段对象：
     ```ts
     export interface AppError {
       detail: string;      // 面向中文用户的可读错误提示，禁止直接暴露英文堆栈
       code: ErrorCode;     // 标准化全大写蛇形错误码
       request_id: string;  // UUID v4 追踪标识
       field?: string;      // 可选，出错字段名
     }
     ```
5. **错误码命名**
   - 统一采用 `DOMAIN_REASON` 全大写蛇形命名，枚举清单固定如下：
     - `CONFIG_INVALID`
     - `STATE_INVALID_TRANSITION`
     - `SCORE_INVALID_KEY_SIGNATURE`
     - `SCORE_INVALID_TIME_SIGNATURE`
     - `SCORE_INVALID_BPM`
     - `SCORE_INVALID_DURATION`
     - `SCORE_MEASURE_NOT_FOUND`
     - `AUDIO_CONTEXT_BLOCKED`
     - `AUDIO_SOUNDFONT_LOAD_FAILED`
     - `STORAGE_QUOTA_EXCEEDED`
     - `STORAGE_SCHEMA_CORRUPTED`
     - `AUTH_UNAUTHORIZED`
     - `AUTH_FORBIDDEN`
     - `RESOURCE_NOT_FOUND`
6. **未登录与越权状态码口径**
   - P0 为纯前端本地应用，无登录与鉴权流程。
   - 预留未来云同步 HTTP 接口固定口径：未登录返回 `401`（错误码 `AUTH_UNAUTHORIZED`）；访问他人曲谱资源返回 `404`（错误码 `RESOURCE_NOT_FOUND`）；已登录但角色或权限不足返回 `403`（错误码 `AUTH_FORBIDDEN`）。
7. **核心共享数据结构契约（`src/domain/types.ts`）**
   ```ts
   export type KeySignature =
     | 'C' | 'G' | 'D' | 'A' | 'E' | 'B'
     | 'F' | 'Bb' | 'Eb' | 'Ab' | 'Db' | 'Gb';

   export type TimeSignature = '2/4' | '3/4' | '4/4' | '6/8';
   export type ViewMode = 'dual' | 'jianpu' | 'staff';
   export type BaseDuration = 'whole' | 'half' | 'quarter' | 'eighth' | 'sixteenth';
   export type Accidental = 'sharp' | 'flat' | 'natural' | null;

   export interface NoteEvent {
     id: string;
     isRest: boolean;
     degree: 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7; // 0 仅当 isRest=true
     octaveOffset: -2 | -1 | 0 | 1 | 2;     // 低音点负值，高音点正值
     accidental: Accidental;
     baseDuration: BaseDuration;
     dotted: boolean;
     durationTicks: number;                  // 由 baseDuration + dotted 确定计算
   }

   export interface Measure {
     id: string;
     index: number;
     notes: NoteEvent[];
   }

   export interface ScoreDocument {
     schemaVersion: 1;
     id: string;
     title: string;
     keySignature: KeySignature;
     timeSignature: TimeSignature;
     bpm: number;                            // 整数，范围 40..200
     viewMode: ViewMode;
     measures: Measure[];
     updatedAtEpochMs: number;
   }

   export interface ResolvedNote {
     noteId: string;
     measureIndex: number;
     startTickInScore: number;
     durationTicks: number;
     midiPitch: number | null;               // 休止符为 null，音符为 0..127
     staffPitchName: string | null;          // 如 "C/4"、"F#/5"，供 VexFlow 渲染
     displayAccidental: Accidental;          // 结合调号与同小节上下文计算出的五线谱显示记号
     stemDirection: 'up' | 'down' | null;
   }

   export interface LayoutSlot {
     noteId: string;
     measureIndex: number;
     lineIndex: number;
     x: number;                              // 双谱共享的绝对横坐标（px）
     width: number;
   }
   ```

## 六、默认假设表

| 编号 | 默认假设 | 理由 | 改动影响 |
|---|---|---|---|
| `A-01` | 首期 MVP 以 `NoteBridge` 仓库根目录直接作为前端 Web 工程根，复用既有 `docs/context/` 并在 `docs/` 下维护交付契约 | 仓库已建立且尚未初始化任何源码与构建配置，避免嵌套子目录增加脚本路径复杂度 | 若后续演进为多端 Monorepo，只需将 Web 源码迁入 `apps/web/` 并调整脚本工作目录 |
| `A-02` | P0 采用纯前端本地优先架构（`localStorage`），不建服务端与数据库 | 需求大纲 P0 聚焦轻量零门槛制谱试听闭环，无账号与云同步诉求 | 若后续增加云存储，需补充后端 API 与 `401/403/404` 鉴权中间件 |
| `A-03` | 包管理器采用实测可用的 `npm`（`11.12.1`），不采用 `pnpm` | 沙盒中 `pnpm` 访问宿主配置报 `EPERM`，`npm` 实测正常 | 若换回宿主机用 `pnpm`，需更新 `AGENTS.md` 安装命令并重生成锁文件 |
| `A-04` | P0 仅支持单声部高音谱号（Treble Clef）旋律记谱 | 初学者与教学单旋律扒谱场景为核心，避免钢琴大谱表分轨阻塞 MVP | 扩展双手大谱表时需在 `Measure` 上增加 `staffIndex` 轨道字段 |

## 七、已知平台限制

1. **无真实音频听觉输出验证**：当前 Windows 执行沙盒无物理声卡人工监听通道，Web Audio 发声质量、钢琴采样音色与节拍器听感在当前环境下无法做主观听觉验收（需在带音箱/耳机的本地浏览器复测）。
2. **沙盒 `pnpm` 权限受限**：实测在沙盒环境下运行 `pnpm --version` 报 `EPERM`；所有依赖安装与脚本执行统一使用 `npm`。
3. **Docker 守护进程不可达**：实测 `docker info` 无法连接 `//./pipe/docker_engine`；本环境无法运行基于容器的隔离构建或测试，需在已启动 Docker Desktop 的宿主机复跑。
4. **本地端口仅同命令可达**：在 Windows 沙盒中启动的 Vite 开发服务器（如 `5173` 端口）仅在同一命令行进程生命周期内可被访问，人工浏览器预览需在宿主机终端或非沙盒环境启动。
5. **移动端真机触控与 Safari AudioContext 限制**：当前 Windows 桌面环境无法复测 iOS Safari 的首次手势解锁音频限制及小屏单手触摸手感，需在 iOS/Android 真机环境复测。
6. **沙盒跨盘 Git 执行受限**：当前沙盒下跨盘执行 `git -C <repo-root>` 返回 `Permission denied`；Git 状态核验、提交与推送需在将该仓库设为活动工作区或宿主机终端执行。
