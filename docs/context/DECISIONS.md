## 二、需求大纲中的建议项（尚未最终拍板）

以下内容来自 [README.md](../../README.md) 需求大纲，属于**推荐方案**而非最终技术选型决定，需在代码初始化前与用户确认：

- **首期目标平台**：纯 Web 应用、桌面端（如 Electron/Tauri）、还是结合 Java 后端/原生移动端（待确认）。
- **五线谱渲染引擎**：建议 VexFlow 或 OpenSheetMusicDisplay（OSMD）（待确认）。
- **音频合成方案**：Web 端建议 Web Audio API 或 Tone.js；移动端原生建议 SoundFont（`.sf2`）（待确认）。
- **时值基准**：大纲建议四分音符 = `480 Ticks`（待核心数据模型落地时确认）。
